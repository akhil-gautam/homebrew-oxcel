# oxcel

A native macOS spreadsheet for very large data: Excel workbooks, CSV, Parquet and SQL
dumps, Postgres, MySQL and SQLite, with billions of rows. Everything runs on your Mac.

**[Buy oxcel](https://buy.polar.sh/polar_cl_gA4jTqfdkmi0jX6Hi1qL8aIO32a52QKvPgwdZ19GUhf)**:
$79 once, a lifetime license for up to 3 Macs. Your license key arrives by email right
after purchase.

## Install

With Homebrew:

```sh
brew install --cask akhil-gautam/oxcel/oxcel
brew upgrade --cask oxcel      # later versions
```

Or download `oxcel-<version>-macos-universal.zip` from
[Releases](https://github.com/akhil-gautam/homebrew-oxcel/releases/latest), unzip it and
drag oxcel.app to Applications. It runs on Apple silicon and Intel Macs (macOS 11+).

Open oxcel, paste your license key and click Activate (this needs the internet once).
Help ▸ License… shows your license and frees this Mac's activation, to move it to
another Mac.

This repository holds oxcel's release downloads and its Homebrew cask; the releases are
published automatically.
