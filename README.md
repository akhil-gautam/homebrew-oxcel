# oxcel

A native macOS spreadsheet for very large data: Excel workbooks, CSV, Parquet and SQL
dumps, Postgres, MySQL and SQLite, with billions of rows. Everything runs on your Mac.

Website: **https://oxcel.pages.dev**

## Install

With Homebrew:

```sh
brew install --cask akhil-gautam/oxcel/oxcel
brew upgrade --cask oxcel      # later versions
```

Or download `oxcel-<version>-macos-universal.zip` from
[Releases](https://github.com/akhil-gautam/homebrew-oxcel/releases/latest), unzip it and
drag oxcel.app to Applications. It runs on Apple silicon and Intel Macs (macOS 11+).

Open oxcel, paste your license key and click Activate. oxcel checks the license when it
starts, and keeps working offline for 30 days after the last check. Help ▸ License…
shows your license and frees this Mac's activation, to move it to another Mac.
